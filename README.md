# Python ToDo List App

This is a simple ToDo List application built using Python.  
This project helps users to add, view, and delete tasks easily.

## 📌 Features
- Add new tasks
- View all tasks
- Delete completed tasks
- Simple and user-friendly

## 🛠️ Technologies Used
- Python

## ▶️ How to Run
1. Make sure Python is installed
2. Download or clone this repository
3. Open terminal / command prompt
4. Run the file:

   python todo.py

## 💡 About the Project
This project is created for learning purpose.  
It helps beginners understand basic Python concepts like:
- Lists
- Loops
- Functions
